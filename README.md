# 🤖 Agentic RAG

> Autonomous Multi-Agent Retrieval-Augmented Generation framework with hybrid semantic search.

## Overview
Agentic RAG orchestrates specialized reasoning agents that plan, retrieve, re-rank, and synthesize answers across heterogeneous document stores.

## Architecture
- **Planner Agent**: Decomposes complex user queries into sub-tasks.
- **Retriever Agent**: Executes hybrid dense/sparse vector search.
- **Critique Agent**: Evaluates hallucinations and factual grounding.
